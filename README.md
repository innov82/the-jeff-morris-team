# The Jeff Morris Team

Custom real estate website. Source is maintained in GitHub and can be synchronized to Lovable.

Run `npm install`, then `npm run dev`. Production build: `npm run build`.

The root HTML and `public/` contain the complete experience. Real property and team photography is supplied by the existing Jeff Morris Team website. Listing data is a curated snapshot, not a live MLS/IDX feed. Inquiries open a visitor's email application; there is no server-side lead collection yet. Saved homes stay in the visitor's browser.
